# 新小岩土地活用 判断シミュレーター

スマホでグラフィカルな画面として見る場合は、GitHubの `index.html` コード画面ではなく、下のプレビューリンクを開いてください。

- [スマホで見る / HTMLプレビュー](https://htmlpreview.github.io/?https://github.com/fhr04265-ctrl/koiwa/blob/main/index.html)
- [index.html のコード](https://github.com/fhr04265-ctrl/koiwa/blob/main/index.html)

## 内容

- 結論サマリー
- 今売る手取りとの比較
- 活用案カード
- NPV差のグラフィカル比較
- 土地価格、賃料、稼働率、建築費、金利の入力変更

## 注意

このHTMLは簡易シミュレーターです。税務、相続、正確な譲渡税、建築条件は簡略化しています。最終判断前に専門家確認が必要です。
