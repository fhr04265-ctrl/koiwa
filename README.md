## 今回の主な更新

- 現在の入力内容をベースケースとして維持
- 大規模改修は1回目を基本計上し、2回目・3回目は「やる / やらない」を選択可能
- 「判定」タブを追加し、事業実行前に確認すべき7項目をカードで表示
- 土地単独承継、資産凍結対策、3年以上の貸付期間は「未確認 / はい / いいえ」で入力
- 建築費40万円/㎡でもDSCR 1.2以上か、家賃10%下落でも年間CFが赤字化しないかを自動判定
- 相続税削減額が建築リスクに見合うか、売却手残り5,000万円前後を上回る合理性があるかを自動判定

## ベースケース

- 一棟あたり一世帯 × 2棟の貸家
- 土地時価は3,600万円
- 建築総額は4,500万円
- 借入金額は3,150万円
- 入居率は90%
- 運営費率は5%
- 法定相続人は2人
- 大規模改修1回目は15年目、350万円
- 2回目以降の大規模改修は任意
- 見る期間は最長50年
- 貸付事業用宅地等④は仮適用を初期値

## 判定タブの7項目

1. 土地を単独承継できる
2. 家族信託・任意後見など資産凍結対策がある
3. 建築費40万円/㎡でもDSCR 1.2以上
4. 家賃10%下落でも年間CFが赤字化しない
5. 3年以上の貸付期間を見込める
6. 相続税削減額が建築リスクに見合う
7. 売却した場合の手残り5,000万円前後を上回る合理性がある

## 貸付事業用宅地等④の前提

今回ケースは、被相続人等の貸付事業の用に供されていた宅地等、すなわち「貸付事業用宅地等④」に該当する想定です。200㎡まで50%減額の対象になり得るため、画面の初期値は「仮適用する」にしています。

現在の土地面積前提は135㎡のため、200㎡枠内に収まります。仮適用時は貸家建付地評価額に対して50%減額を反映します。

ただし、貸付開始時期、相続開始までの期間、申告期限までの事業継続、取得者、分割状況などで適用可否が変わります。画面では「仮適用」として扱います。

## 注意

このHTMLは意思決定前の簡易シミュレーターです。相続税評価、固定資産税、譲渡税、取得費、減価償却、消費税、都市計画税、新築軽減、修繕費と資本的支出の区分、融資条件、建築条件は簡略化しています。最終判断前に税理士、金融機関、建築士、不動産会社で確認してください。
