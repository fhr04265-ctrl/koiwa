## ベースケース

- シミュレーション本体は「一棟あたり一世帯 × 2棟の貸家」
- 家賃は一棟あたり月10万〜20万円を入力可能
- 土地時価は3,600万円
- 建築総額は4,500万円
- 入居率は90%
- 運営費率は5%
- 法定相続人は2人
- 大規模改修は15年目、350万円
- 家賃は築年数による低下を織り込めるよう、10年単位で入力
- 大規模改修は最大3回まで、回数と年を入力
- 見る期間は最長50年

## 相続税ロジックの前提

このツールの相続税は、国税庁の説明に沿って、次の簡易フローで概算します。

1. 正味の遺産額を出す
2. 基礎控除 `3,000万円 + 600万円 × 法定相続人の数` を差し引く
3. 課税遺産総額を法定相続分で分けたものとして計算する
4. 相続税の速算表を使い、各人分を合計する

未反映のものがあります。配偶者の税額軽減、相続税の2割加算、生命保険非課税枠、生前贈与加算、相次相続控除、未成年者控除、障害者控除などは、この簡易ツールでは反映していません。

## 小規模宅地等の特例

貸付事業用宅地等として要件を満たす場合、200㎡まで50%減額される前提で切替できます。ただし、貸付開始時期、相続開始までの期間、申告期限までの事業継続、取得者、分割状況などで適用可否が変わります。画面では「仮適用」として扱います。
