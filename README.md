## ベースケース

- シミュレーション本体は「一棟あたり一世帯 × 2棟の貸家」
- 土地時価は3,600万円
- 建築総額は4,500万円
- 入居率は90%
- 運営費率は5%
- 法定相続人は2人
- 大規模改修は15年目、350万円
- 見る期間は最長50年

## 貸付事業用宅地等 ④の前提

今回ケースは、被相続人等の貸付事業の用に供されていた宅地等、すなわち「貸付事業用宅地等 ④」に該当する想定です。貸付事業用宅地等 ④は、200㎡まで50%減額の対象になり得るため、画面の初期値は「仮適用する」にしています。

現在の土地面積前提は135㎡のため、200㎡枠内に収まります。したがって、仮適用時は貸家建付地評価額に対して50%減額を反映します。

ただし、貸付開始時期、相続開始までの期間、申告期限までの事業継続、取得者、分割状況などで適用可否が変わります。画面では「仮適用」として扱います。

## 相続税ロジックの前提

このツールの相続税は、国税庁の説明に沿って、次の簡易フローで概算します。

1. 正味の遺産額を出す
2. 基礎控除 `3,000万円 + 600万円 × 法定相続人の数` を差し引く
3. 課税遺産総額を法定相続分で分けたものとして計算する
4. 相続税の速算表を使い、各人分を合計する

未反映のものがあります。配偶者の税額軽減、相続税の2割加算、生命保険非課税枠、生前贈与加算、相次相続控除、未成年者控除、障害者控除などは、この簡易ツールでは反映していません。

## 注意

このHTMLは意思決定前の簡易シミュレーターです。相続税評価、固定資産税、譲渡税、取得費、減価償却、消費税、都市計画税、新築軽減、修繕費と資本的支出の区分、融資条件、建築条件は簡略化しています。最終判断前に税理士、金融機関、建築士、不動産会社で確認してください。
