## 今回の前提

- 金額はすべて「万円」単位
- 難しい `NPV` という表現は使わず、「今の価値で見た得失」として表示
- 相続税の軽減見込みを簡易的に加味
- ベースケースは「2棟アパート建設」を有力案として想定

## 注意

このHTMLは簡易シミュレーターです。相続税評価、小規模宅地、借地権、消費税、譲渡税、建築条件は簡略化しています。最終判断前に税理士・建築士・不動産会社で確認してください。
