## 判定タブの7項目

1. 土地を単独承継できる
2. 家族信託・任意後見など資産凍結対策がある
3. 建築費40万円/㎡でもDSCR 1.2以上
4. 家賃10%下落でも年間CFが赤字化しない
5. 3年以上の貸付期間を見込める
6. 相続税削減額が建築リスクに見合う
7. そのまま売却より合理性がある

## 貸付事業用宅地等④の前提

今回ケースは、被相続人等の貸付事業の用に供されていた宅地等、すなわち「貸付事業用宅地等④」に該当する想定です。200㎡まで50%減額の対象になり得るため、画面の初期値は「仮適用する」にしています。

現在の土地面積前提は135㎡のため、200㎡枠内に収まります。仮適用時は貸家建付地評価額に対して50%減額を反映します。

ただし、貸付開始時期、相続開始までの期間、申告期限までの事業継続、取得者、分割状況などで適用可否が変わります。画面では「仮適用」として扱います。

## 注意

このHTMLは意思決定前の簡易シミュレーターです。相続税評価、固定資産税、譲渡税、取得費、減価償却、消費税、都市計画税、新築軽減、修繕費と資本的支出の区分、融資条件、建築条件は簡略化しています。最終判断前に税理士、金融機関、建築士、不動産会社で確認してください。
