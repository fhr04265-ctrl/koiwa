## 今回の前提

- シミュレーション本体は「一棟あたり一世帯 × 2棟の貸家」に限定
- 家賃は一棟あたり月10万〜20万円を入力可能
- ベースケースは土地時価3,600万円、建築総額4,500万円、入居率90％
- ベースケースは運営費率5％、法定相続人2人
- 金額はすべて「万円」単位、割合は「％」単位で表示
- 固定資産税は土地時価・建築総額から自動で簡易試算
- 画面上部に結論、収支カード、年次グラフを配置
- 入力欄は画面下部にまとめ、スマホでも触りやすい折りたたみ式セクションに整理
- 年次グラフは、左軸に年間収支の棒グラフ、右軸に累積収支の折れ線を表示
- 累積収支は、初期自己資金、ローン返済、税金、改修費、最終売却を含む現金ベースの概算
- グラフをタップすると、売上、運営費、固定資産税、改修費、返済・税、年間収支、累積収支、累計改修費を確認可能

## 入力する項目

入力項目は、見積・査定・家族条件から実際に決める必要があるものに絞っています。

### 家賃・建築

- 一棟あたり家賃（万円/月）: 1棟を貸したときの月額家賃
- 入居率（％）: 家賃が入る割合。空室リスクを見るための項目。ベースケースは90％
- 建築総額（万円）: 2棟合計の建築費。外構・設計・諸費用も含めた見積額。ベースケースは4,500万円

### 借入

- 借入金額（万円）: 銀行から借りる金額。建築総額を超える場合は、計算上は建築総額までとして扱います
- 金利（％/年）: ローンの年利
- 見る期間（年）: 何年分の収支を見るか。通常は30年

### 運営・改修

- 運営費率（％）: 管理費、募集費、保険、小さな修繕などの割合。ベースケースは5％
- 毎年の修繕積立（万円/年）: 屋根・外壁・設備交換に備えるお金
- 15年目の大規模改修費（万円）: まとまって出る改修費

### 相続税・納税資金

- 土地時価（万円）: いま売るならいくらかという売却査定額。ベースケースは3,600万円
- 法定相続人（人）: 基礎控除の計算に使う人数。ベースケースは2人
- 他の財産（万円）: 預金、有価証券、他の不動産など
- 他の債務（万円）: この計画以外の借入や未払金
- 残したい現預金（万円）: 相続税を払った後も手元に残しておきたい現金
- 想定相続税率（％）: 大まかな税率。分からなければ初期値の30％で試算

## 固定前提にしたもの

初心者でも扱いやすくするため、細かい税務・評価係数は画面上で入力させず、固定前提にしています。

- 土地評価は時価の80％として概算
- 建物評価は建築費の55％として概算
- 固定資産税は、土地評価額に小規模住宅用地の簡易特例1/6と税率1.4％、建物評価額に税率1.4％を掛けて概算
- 都市計画税、新築住宅の軽減、自治体ごとの評価補正は未反映
- 借地権割合60％、借家権割合30％、賃貸割合100％として概算
- 小規模宅地等は適用ありの初期前提
- 葬式費用は200万円として概算
- ローン期間は30年として概算

## 注意

このHTMLは簡易シミュレーターです。相続税評価、小規模宅地等の適用要件、借地権割合、空室の扱い、消費税、譲渡税、建築条件、修繕費と資本的支出の税務上の違いは簡略化しています。最終判断前に税理士・建築士・不動産会社で確認してください。
