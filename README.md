## 今回の前提

- シミュレーション本体は「一棟あたり一世帯 × 2棟の貸家」に限定
- 家賃は一棟あたり月10万〜20万円を入力可能
- 金額はすべて「万円」単位
- `NPV` という表現は使わず、「今の価値で見た得失」として表示
- 相続税は、貸家建付地・貸家評価・小規模宅地等・基礎控除・借入控除を入力して概算
- 売上、通常コスト、改修費、返済、税、年間手残り、累計手残りを年次で確認可能
- 駐車場、売却、定期借地、現況維持は別タブの参考メモに整理

## 注意

このHTMLは簡易シミュレーターです。相続税評価、小規模宅地等の適用要件、借地権割合、空室の扱い、消費税、譲渡税、建築条件は簡略化しています。最終判断前に税理士・建築士・不動産会社で確認してください。
